# Research Tasks 高保真原型

根据 `../docs/research_tasks_frontend_design_spec_v1.docx` 制作的中文桌面端交互原型。无需安装依赖或构建。

## 本地查看

在此目录运行：

```bash
python -m http.server 4173 --directory dist
```

打开 `http://localhost:4173`。也可以直接用浏览器打开 `dist/index.html`，但本地存储行为取决于浏览器对文件地址的支持。

## 可体验流程

- 今天：按时间查看任务、标记完成、展开逾期和已完成事项。
- 收集箱：快速记录、多选整理；未提供的日期不会被补全。
- 全部任务：搜索、类型 / 状态 / 优先级 / 日期筛选、列表和看板切换。
- 任务详情：编辑、调整计划日期、确认删除，以及提示条撤销。
- 日历：日 / 周 / 月切换、日期导航、点击工作块或空白时段。
- AI：`Cmd/Ctrl + K` 唤起；模拟创建、查询、排程预览，确认后写入本地数据。支持示例指令，非通用语言理解。
- 投稿：查看、添加和编辑阶段、日期、明确时区及提醒偏好。
- 通知和设置：标记已读、稍后处理、保存本地偏好。

## 演示边界

场景基准日为 **2026-10-30**。任务与组会为演示数据；ICLR 2027、CVPR 2027 的摘要、全文、答辩及通知日期参照 [CCF-Deadlines](https://github.com/ccfddl/ccf-deadlines) 的 2026-10-30 本地快照，保留秒和 UTC−12 / AoE 时区。个人投稿阶段与准备事项仍是示例。数据不会自动更新，详情面板提供 YAML 来源与会议官网链接。旧版本未修改的虚构日期会自动迁移，用户已编辑的日期不会被覆盖。数据保存在当前浏览器的 `localStorage`，不连接账号、模型、外部软件或后端，不产生真实推送。日历拖拽、离线同步、真实 AI 与跨时区转换不在此原型范围内。可在开发者工具中删除 `research-tasks-prototype-v1` 存储项恢复初始数据。

源码位于 `dist/`，其中 `styles.css` 定义设计 Token 和响应式布局，`app.js` 实现交互，`index.html` 是入口。`.openai/hosting.json` 保存此原型的 Sites 身份。
