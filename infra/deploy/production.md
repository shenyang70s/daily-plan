# Production 发布前条件

尚未选择生产环境，也未执行公开发布。需要明确授权后，才在目标环境操作。

发布前需具备：带本地持久化磁盘的单实例主机、准确 HTTPS 域名与反向代理、独立数据库、服务端密钥、独立持久化备份位置和负责恢复的操作者。SQLite 不放入镜像、不使用网络共享文件、不以多个应用副本共同写入。

先完成 [Staging 验收](staging.md)，再使用同一个已验证源码版本的镜像。`BUILD_REVISION` 必须是实际构建提交，镜像标签和 OCI revision 标签保持一致；不要使用可变的 `latest` 作为回退记录。

按 [运行手册](runbook.md) 备份、停写、迁移并启动。应用启动仅追加本版本迁移；如果新旧版本均需运行，数据库改动遵守 Expand/Contract，不能直接删除旧应用仍使用的字段。涉及表重建时，单独验证索引、外键和已有数据。

当前迁移校验会拒绝未知或修改过的历史，因此不能默认旧镜像可直接打开新结构。回退优先使用升级前备份恢复到新路径，再启动匹配的旧版本；上线后的新写入不会出现在升级前备份中，回退前必须另做当前库快照并确认数据损失窗口。

生产密钥、主机信息、用户数据不提交仓库。备份包含认证与私人研究数据，应限制文件和目录权限，按部署策略加密、异地保留并定期演练恢复；账户删除不会自动清除历史离线备份。
