# Today 自然语言安排入口修正

以用户指定的原型交互修正：Today 仅保留自然语言输入入口，回车/发送打开独立 AI 安排弹窗并自动解析；全局搜索继续由顶部入口/Ctrl+K 提供。移除 Today 顶部和列表下方重复的添加按钮。

输入携带 capture 意图，模型输出任务草案/追问，不执行搜索。明确计划时段与截止期限分开解析；未指定时段时按工作时间、预计时长和真实日历空档推荐，推荐及默认时长在预览中展示。用户可修改；确认通过既有任务/任务+工作块原子 API 保存，取消和解析阶段无业务写入。不提前实现通用批量提案、已有任务改期或审计系统。
